# PAL: A Pre-Specified Panel of Artificial Listeners

Code, analysis plan, results, and manuscript for

> **PAL: A Pre-Specified Panel of Artificial Listeners for Pronunciation Recoverability Measurement** (submitted to ICASSP 2027).

PAL treats a panel of heterogeneous speech recognizers as artificial listeners. Each recognizer transcribes a learner's reading of a known prompt; its phoneme error rate against the prompt is one measurement of how recoverable the pronunciation is, and the equal-weight mean over the panel is the readout. No weight, threshold, or predictor is fitted to human ratings.

## Study design

All design choices were fixed on the speechocean762 training split. The analysis plan for the confirmatory stages was then committed (`0525275`, 2026-09-13 20:44 JST; the commit dates are those of the original working history). After that commit, five corpora were analysed once each in a fixed order, with one pre-specified primary comparison per corpus:

| Corpus | Primary comparison | Result |
|---|---|---|
| speechocean762 test | PAL − best single listener (accuracy) | +0.038 [+0.021, +0.056] |
| ERJ | segmental − rhythm correlation | +0.440 [+0.366, +0.516] |
| EpaDB | correlation with phrase score | 0.415 [0.301, 0.491] |
| ALLSSTAR | talker-level correlation with human word recovery | 0.576 [0.404, 0.713] |
| OMPAL | tone − consonant correlation of the tone channel | +0.196 [+0.099, +0.293] |

The corpora are public and had been used by the authors before; "after protocol commitment" is a guarantee about this analysis pipeline, not a claim of first exposure. The plan was not lodged with an external registry.

## Reproducing the reported statistics

```sh
python src/reproduce.py          # primary comparisons from results/errors_*.csv + corpus ratings
Rscript paper/figures.R && python paper/make_numbers.py && python paper/build.py
```

`reproduce.py` needs the corpora's published ratings (speechocean762, ERJ, EpaDB, ALLSSTAR, OMPAL); set `PAL_DATA` to the directory holding their manifests. Transcripts and ratings are not redistributed. Python dependencies: numpy, pandas, g2p_en, phonemizer (eSpeak NG), pypinyin, opencc; R: ggplot2, ggrepel, jsonlite.
