# 01 前提

## 認めるアイデア

学習者が既知のプロンプト（文）を読んだ音声を、性質の異なる複数の ASR に転写させる。各 ASR の転写とプロンプトの差は、その ASR にとって「そのプロンプトがどれだけ回復できたか」の記録である。複数の異質な ASR を並べれば、特定の ASR の癖に依存しない回復可能性（recoverability）の測定になりうる。この文書群は、この着想を測定器として設計し、その妥当性を検証する。

## 計算資源

ローカル（Apple Silicon、gop の Python 仮想環境：numpy / pandas / g2p_en / phonemizer / jiwer）と、必要なら Modal のクラウド CPU/GPU。

## 意図的に「未知」とする情報

- どの ASR が人間評定とよく相関したか、どのパネル構成が良かったか、どの集約規則が良かったか。
- 過去に報告した相関値、表、図、査読コメント。
- 過去のパネル名（PAL-11 / PAL-29 等）とその凍結履歴。

これらは設計判断に使わない。設計が固まった後、比較のために参照することはあり得るが、その場合は `05_workplan.md` の関門を越えた後に、参照した事実を記録する。
