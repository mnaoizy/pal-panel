# 02 研究設問と仮説

## 中心となる設問

**Q. 異質な複数の ASR が既知プロンプトを回復する際の誤りを平均した量は、学習者音声の「回復可能性」の測定として、人間の判断とどのように対応し、何を測っていて何を測っていないか。**

これは「ASR でスコアを予測する」設問ではない。測定器を作り、その妥当性（構成概念妥当性・基準関連妥当性）と信頼性を調べる設問である。

## 反証可能な仮説

各仮説には、確認段階で用いる**判定規則**を付す。判定規則は `03_design_protocol.md` の統計手順に従う。

| ID | 仮説 | 予測される観測 | 反証される観測 |
|---|---|---|---|
| H1 信号 | パネル平均誤り率（の負号）は、人間の分節的な発音評定と正の相関を持つ | 話者クラスタ bootstrap の 95% 区間が 0 を上回る | 区間が 0 を含む |
| H2 集約 | パネル平均は、開発データで選んだ最良の単一 ASR より人間評定との相関が高い | paired 差の区間が 0 を上回る | 区間が 0 を含む、または負 |
| H3 多様性 | サイズと平均誤り率を揃えたとき、複数 family にまたがるパネルは単一 family のパネルより相関が高い | matched 比較の paired 差が正で区間が 0 を上回る | 区間が 0 を含む（多様性の利点は確認されない） |
| H4 構成概念 | 転写比較の読み出しは、分節評定との相関が韻律評定（rhythm / intonation）との相関より高い | 同一話者再標本内の paired 差が正で区間が 0 を上回る | 差が 0 近傍 |
| H5 基準関連 | 読み出しは、専門家評定だけでなく、実際の聴取者の単語回復率と相関する | 話者レベル相関の区間が 0 を上回る | 区間が 0 を含む |
| H6 声調への拡張 | 声調を担う転写表現（ピンイン声調記号）の誤りは、声調評定と子音評定より強く相関する | paired 差が正で区間が 0 を上回る | 差が 0 近傍 |
| H7 弱い ASR の情報 | 平均誤り率が高い（弱い）ASR だけの部分パネルでも、人間評定との相関は単一の強い ASR と同程度以上に残る | 弱パネルの相関が最良単一 ASR の相関を下回らない | 弱パネルが明確に劣る |

## 補助的な設問（探索段階で扱う）

- 読み出しの粒度（音素 / 文字 / 単語）は結果を変えるか。
- 集約規則（平均 / 中央値 / 重み付き / 最小）は結果を変えるか。
- 発話時間などの非分節的な特徴を加えると、fluency 系の評定に対する相関はどう変わるか。これは別の測定チャネルであり、H1–H7 の検証には含めない。
- パネルの大きさに対する相関の飽和。

## 仮説にしないこと

- 「絶対的な発音の等級を出せる」：この測定は相対尺度であり、絶対等級は別途較正が必要。
- 「母語話者らしさを測る」：測るのは既知プロンプトの回復可能性であり、nativelikeness ではない。
