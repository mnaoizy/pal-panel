# 03 測定設計と検証プロトコル

## 1. 測定モデル

- 対象：既知プロンプト $t$ を読んだ発話 $u$。
- 測定器：$K$ 個の認識器（listener）$k=1..K$。各認識器は仮説転写 $h_k(u)$ を返す。
- 単位化：プロンプトと仮説を**同一の**処理（正規化→音素列化）で音素列にし、編集距離を参照長で割った音素誤り率 $e_k(u)\in[0,1]$（上限 1）を取る。空の仮説は $e_k(u)=1$。
- 読み出し：$p(u) = -\frac{1}{K}\sum_k e_k(u)$。**重みは学習しない**。$p$ は相対尺度（アフィン変換に不変な相関で評価する）。
- 解釈：$p(u)$ が大きいほど、異質な聴き手にとってプロンプトが回復しやすい発話。

音素列化の仕様（英語）：小文字化、アポストロフィ以外の ASCII 句読点を空白化、数字は 1 桁ずつ英単語化、空白を圧縮、単語ごとに g2p_en で ARPAbet に変換し強勢数字を除去。音素認識器（espeak-phone, allosaurus-eng）は、プロンプトを eSpeak（en-us）で IPA 音素列にした参照と、出力トークン列を直接比較する（音素体系の写像は行わない。これは限界として記録する）。

中国語（OMPAL）：繁体→簡体正規化、漢字列の文字誤り率、ピンイン（TONE3）から音節基底列と声調記号列を分けてそれぞれの誤り率を取る。

## 2. パネル採用規則（結果を見る前に固定）

1. 公開重みで動く、対象言語（または汎用音素）に対応した認識器であること。
2. **音響チェックポイントごとに 1 構成**。同一チェックポイントのデコーダ変種（言語モデル重みの掃引など）は採用しない。
3. 人工的に劣化させた入力の構成は採用しない。
4. チェックポイントの同一性が目録で確認できない構成は採用しない。
5. 上記を満たす構成は**すべて**採用し、性能による選別はしない。

この規則を SO762 の 32 構成に適用した結果（`pipeline/inventory.py`）：`w2v2lm_a0.5 / a1.0 / a2.0`（wav2vec2-base のデコーダ変種）、`base.en@snr10 / parakeet@snr10`（人工劣化）、`xlsr-cv-en`（チェックポイント不明）を除外し、**28 構成**を英語パネルとする。

family の付与（アーキテクチャ×学習データ、事前に定義）：GMM-HMM、Kaldi 系ハイブリッド、畳み込み CTC、自己教師あり CTC（LibriSpeech 系）、自己教師あり CTC（別ドメイン：Common Voice / 電話 / 航空無線）、Whisper 系、その他エンコーダ・デコーダ、トランスデューサ、音声 LLM、音素認識器。

## 3. データの役割と開封順（固定）

| 段階 | データ | 用途 | 状態 |
|---|---|---|---|
| 開発 | SO762 **train** split（2,500 発話・125 話者） | 読み出し・パネル規則・統計手順の全決定、探索的分析 | 開封済み |
| 確認 1 | SO762 **test** split | H1, H2, H3, H7 の確認。**1 回だけ**実行 | 未開封 |
| 確認 2 | ERJ | H4（構成概念）。読み出し・パネルは確認 1 の前に凍結 | 未開封（redo としては） |
| 確認 3 | EpaDB | H1 の別母語・別録音条件での再現 | 未開封 |
| 確認 4 | ALLSSTAR | H5（基準関連） | 未開封 |
| 確認 5 | OMPAL | H6（声調） | 未開封 |

規則：確認段階のデータを見た後に読み出し・パネル・統計手順を変更しない。変更が必要なら、その段階以降を「探索」として再ラベルし、新しい確認データを別途用意する。開封の前に `04_preregistration_confirmatory.md` を記入し、内容を git にコミットしてから解析する。

## 4. 統計手順

- 相関：Pearson r（発話単位。ALLSSTAR は話者単位）。
- 不確実性：話者（ALLSSTAR は話者＝talker）を単位とするクラスタ bootstrap、B=2,000、seed=20260913、percentile 95% 区間。
- 対応のある比較：同じ再標本上で両方の相関を計算し、差の分布を取る。
- 判定：主要仮説ごとに 1 つの主要比較を事前に指定。副次比較は探索的とし補正しない旨を明記。

## 5. 判定規則の具体化

- H2 の「最良の単一 ASR」は、開発データ（SO762 train）の accuracy 相関で選ぶ。確認 1 では同じ ASR を固定して比較する。
- H3 の「matched」：同一 family パネル（メンバー数 $k$）に対し、family をまたいで 1 名ずつ選んだ $k$ 名のランダムパネルのうち、train 平均誤り率と train 相関の平均が同一 family パネルの ±0.03 / ±0.02 に入るものを 200 組採択して平均する。
- H7 の「弱い ASR」：train 平均誤り率の上位（誤りが大きい）1/3。

## 6. 主な脅威と対策

| 脅威 | 対策 |
|---|---|
| 開発データでの選別が確認段階に漏れる | 開封順と凍結。パネルは規則で決め、性能で選ばない |
| 転写が過去の実行の産物で再実行できない | 目録でモデル・行数・空出力率を記録。空出力は誤り 1 として扱い、率を報告 |
| プロンプト長や録音条件が相関を作る | 相関は発話内の比較なので長さの影響は限定的だが、参照音素数との相関を報告する |
| 評定間の重なり（accuracy と fluency の高い相関） | 分節と韻律が別評定として与えられる ERJ で構成概念を切り分ける（H4） |
| 単一コーパス過適合 | 4 つの外部コーパスと 1 つの人間聴取基準で確認 |
