# 05 作業計画と関門

| 段階 | 内容 | 関門（次に進む条件） |
|---|---|---|
| 0 | 前提・設問・設計・目録（本文書群） | 目録が全コーパスの転写の有無と行数を示す |
| 1 開発 | SO762 train で読み出しを実装し、H1/H2/H3/H7 を探索的に検討。集約規則・粒度・飽和も探索 | 読み出し仕様・パネル規則・統計手順を変更しないと宣言し、`04` に記入してコミット |
| 2 確認 1 | SO762 test を 1 回だけ解析 | 結果を記録。以後 SO762 test に基づく変更は行わない |
| 3 確認 2–5 | ERJ → EpaDB → ALLSSTAR → OMPAL の順に、各 1 回 | 各段階の事前登録と記録 |
| 4 二次チャネル | 発話時間など非分節特徴の設計（開発データのみ）と、必要なら別の確認データ | 分節読み出しの結論を変えないこと |
| 5 報告 | 測定器としての仕様、妥当性の証拠、限界（相対尺度、韻律を測らない、転写の再現性） | 全数値が `results/` の生成物から再現できる |

現在地：段階 5（報告）。確認段階の記録は `07_confirmatory_report.md`、論文は `paper/output/pal_redo.pdf`、旧原稿との比較は `08_comparison.md`。
