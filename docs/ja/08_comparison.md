# 08 旧原稿との比較（何が「優れている」か）

比較対象：`output/pdf/pal_icassp2027_authors.pdf`（旧原稿、第四回レビュー対応後）と `redo/paper/output/pal_redo.pdf`（本原稿）。

| 観点 | 旧原稿 | 本原稿 |
|---|---|---|
| 証拠の構造 | SO762 test は listener 追加中に参照されており、本文で development benchmark と断る必要があった | 開発は SO762 train のみ。test を含む 5 コーパスは事前登録（git commit `f363d98`）後に各 1 回だけ解析。主要比較 5 件すべて判定規則を満たす |
| パネル | PAL-11 / PAL-29 / PAL-ZH-8 とコーパスで構成が異なり、凍結履歴の説明が必要だった | 事前規則で採用した **28 構成を全英語コーパスで共通**に使用（中国語 8） |
| 単一認識器との比較 | test 上で最良の HuBERT（train でも最良）と比較 | train で固定した HuBERT と、test・EpaDB・ALLSSTAR で paired 比較 |
| 多様性の主張 | matched cross-family 比較を事後に追加 | H3 として事前に仮説化し、train で採択した 200 組を test に持ち越して検証。ALLSSTAR では確認されないことも明記 |
| 弱い認識器 | 点推定の比較 | H7 として事前に固定した「誤り率上位 1/3」を test で paired 比較（+0.016 [−0.001, +0.034]：最良単一と同程度） |
| duration チャネル | fluency/total の主結果として掲載し、査読で繰り返し指摘された | 分節読み出しに限定。時間チャネルは「別の測定器」として限界節に位置づけ |
| 声調 | 凍結 bank と再デコードの併記 | 再デコード転写のみを用い、tone − consonant を主要比較、基底一致条件を副次に |
| 数値の出所 | gop の多数のスクリプト・保存結果を横断 | `redo/results/*.json` と `redo/pipeline/`（既存コード非依存、マクロを自動生成） |
| 紙面 | 4 ページぎりぎり、表 4・図 1 | 約 3.7 ページ、表 3・図 2（認識器の強さ vs 相関の図を追加） |

数値面では、旧原稿の SO762 test accuracy 0.670 に対し本原稿は 0.671（28 構成、LM 変種を除外）、ERJ segmental 0.607（PAL-11）に対し 0.597（28 構成）、ALLSSTAR 0.579 に対し 0.576 で、ほぼ同等。優位性は性能ではなく、**主張と証拠の対応の明確さ**と**再現手順の単純さ**にある。

## 残る限界

- 転写は過去の実行の産物で、モデル revision は未固定（旧原稿と同じ）。
- 事前登録は同一セッション内で作成・実行したため、第三者による時刻証明はない（git の commit 時刻のみ）。
- OMPAL の 8 構成はもともと OMPAL の相関を見ながら集められた経緯があるが、本 redo ではその情報を使っていない。
